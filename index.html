How updates work

When installed using GitHub Pages + the included GitHub Actions workflow, Penny Scout requests a new public report snapshot four times per day. The app checks for newer feed data whenever you open it and when you tap Refresh. A basic static ZIP upload is NOT automatically refreshed on the server.

No push notifications while the app is closed. New leads are highlighted when you open it. If the upstream feed becomes unavailable, the last snapshot remains available with its date shown.
